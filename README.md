# Design Detective — HCI 2
Static HTML, CSS and JavaScript only. Ten challenges, final-only feedback, printable certificate with professor name Khaela May Lee, MIT. No signature image, database or backend.

## Local test
Run `python -m http.server 8000` in this folder and visit http://localhost:8000.

## Render
Upload these files to the root of your HCI2 GitHub repository. Select Static Site, branch main, root directory blank, build command `echo Ready`, publish directory `.`. No start command or environment variables needed.

Progress is stored in the browser tab session. Scores are client-side and not tamper-proof. No centralized records.

Choose Good Design or Bad Design, then click Next challenge. The final item shows Finish game. You can change your selection before confirming. The site also opens directly from index.html without a local server. No external libraries or network dependencies. Certificate includes professor name only, no signature.
